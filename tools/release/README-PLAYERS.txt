Innworld RPG
============
Version {VERSION}

A free, fan-made, non-commercial RPG set in pirateaba's Innworld.
You play an unnamed Earther. You arrive at the start of Book 1.
The books and the world belong to pirateaba. This game holds no book text.

This is an ALPHA build. Expect bugs and rough edges.
Canon events from Books 1 to 6 are in the game.


START THE GAME
--------------
Windows: unzip the folder. Double-click InnworldRPG.exe.
  Windows SmartScreen can warn you, because the file has no signature.
  Click "More info", then "Run anyway".
Linux:   unzip the folder. In a terminal, run:
  chmod +x InnworldRPG.x86_64
  ./InnworldRPG.x86_64

You need a keyboard. There are no touch controls yet.


KEYS
----
WASD / arrows   walk (walk into a monster: attack)
Space           wait (in a fight: end your turn)
Mouse           in a fight: click a blue tile to walk, a foe to attack
1-9             use a Skill or spell in a fight
B / T / X       block / throw the held item / drop the held item
E               use or take what is next to you
F               eat
I               bag
Z               sleep (the night moves the world)
C               character
J               journal
L               message history
H               all keys
Esc             menu (save, load, quit)

The game saves itself each morning.


SAVES AND SETTINGS
------------------
Windows: %APPDATA%\Godot\app_userdata\Innworld RPG
Linux:   ~/.local/share/godot/app_userdata/Innworld RPG
Saves from an alpha build may not load in a later build.
