## Conventions to keep (same as Books 7 and 8)
- Event ids `b9.`; data in `game/data/canon/book9/` (`npcs.json`, `locations.json`, `chapters/<ch>.json`).
  `CanonDb` loads a new book folder with no loader change (confirm with a test).
- Chapter `order`: Book 8 ends at 77, so Book 9 starts at **78** (22 chapters: 78 – 99).
- Laken's "Day N" + 45 = game day (ADR 0028). Liscor chapters have few day numbers: mark guessed days
  `"confidence": "guess"`.
- Own words only; short summaries plus chapter references (Rule 10). A copy check (7-word runs) is in the
  validator: reword and rerun when it hits.
- Fight stages (`xp_window` x3, `foreshadow`, `beats`, hooks) only where the user picks them. Ask the stage
  and hook choices at the start of each batch (M28 pattern). A reading agent proposes; the user picks.
- Scene beats and signposts (M31) apply to any stage you add: `foreshadow` before it, `beats` on it.
- Deaths: `kill` effects and a `sim_kill_book9` for named deaths (ADR 0036 rules). Records fixed from the text:
  levels, classes, Skills (`confidence`), `status`.
- Voices (`voices.json`) are not part of this milestone unless the user asks.
