# M33 — Depth: spells, dishes, quests, friends: plan

Status: PROPOSED (2026-10-17, ADR 0044). Source: `docs/AUDIT_PLAYER_2026-10-17.md` finding 7.
Last of the audit milestones. One branch + PR per step. Book text goes to reading agents (summaries only).

## Goal
A reader can live the fantasies the books plant: learn real spells from Pisces or Ceria, cook Erin's food, follow a
friend's story, and feel a friendship do something.

## Today
- 5 spells, all damage shapes (`one`, `line`, `around`, `blast`): [Ice Spike], [Flashfire], [Gust], [Frozen Wind],
  [Fireball] (`data/spells.json`). [Mage], [Necromancer], [Illusionist] classes exist.
- 8 recipes (`data/recipes.json`), mostly generic (simple meal, stew, roast meat).
- Jobs pay coin with no story (`economy.json` "jobs"). No quest system.
- Friendship: greetings, prices (`price_per_point`), friends help in fights (`friend_fight` 10). Nothing else.

### M33.2 build plan (user picks 2026-10-26)
User picks: a quest starts from an auto talk row on its giver; a spell reward unlocks the teacher (a flag).
- **`data/quests.json`** `{"quests": {id: quest}}`. A quest: `title`, `giver` (canon NPC), `offer` (what the giver
  says, own words), optional `gate` (`flags`, `not_flags`, `days`, `min_band`, as in voices), optional `fail`
  (`flags`, `after_day`; the giver's death always fails it), `steps` (1+; each `text` and either `flag` (a flag
  is set) or `did` (the event-hook matcher, `Director.record_matches`) with optional `count`), `rewards`
  (`relationship` with the giver, `coins` in copper, `goods` {good: n}, `flags`), optional `done` (what the giver
  says at the end), `confidence`, `canon_ref`, `note`. No quests in the file yet (M33.3 adds the lines).
- **Start:** when the gate passes, the giver's talk menu has "Ask about: <title>" (`Interact.QUEST`, "quest:<id>").
  It runs the first talk action (`rules.npc.talk_actions[0]`) and starts the quest.
- **Progress:** `Actions.perform` sends each record to `Quests.after_action` (a `did` step counts only records made
  while it is the current step). `Commands._after` and `Night.run` (after the director) call `Quests.update`:
  flag steps, fail checks, rewards. A "go back to the giver" step is a `did` step on `talk_with_guest` with
  context `{"npc": giver}`.
- **Spell teacher unlock:** spell `learn.flags` (all must be set; needs a teacher). A quest reward sets the flag.
- **State:** new `core/quest_state.gd` (`gs.quests`): id to {status active / done / failed, step, count, day,
  end_day}. Save v24 + migration (empty).
- **Journal:** a "Tasks" part: the current step of each open task, then done and failed ones.
- Checks: `Quests.validate` (DataDb load errors) and `tools/validate_data.py --all` (quests.json).
- Tests: `unit_quests` (new), `unit_journal`, `unit_voice`, `unit_interact`, `unit_player_hooks`, `unit_game_state`,
  `unit_save_slots`, `unit_player_identity`, `unit_spell_learning`, `unit_data_db`; Python tests; validator.
