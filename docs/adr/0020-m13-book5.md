## Decisions
- **Exits gated by flags (M13.0).** An exit can have `id`, `when_flags` and `unless_flags`. A hidden exit is
  plain floor for movement, pathfinding, monsters and NPCs. The flag cache is shared by every game on one
  db, so the validator reads raw exits. A gated exit needs a unique `id`, and its target map needs an ungated
  way back.
- **Traps are map data, not objects (M13.T).** Their state (`found`, `spent`, `disarmed`) is saved in
  `CombatState.traps`, changes only. All rolls go through the seeded RNG (rule 3). Save v14.
- **Enemy `look` (M13.0).** An enemy can borrow another enemy's art (`cave_goblin` → `goblin_grunt`).
- **The depths use existing tiles** (`cave_floor`, `rock`). A new tile would need new art.
