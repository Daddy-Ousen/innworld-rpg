# ADR 0019 — M12 audio: music, sound effects and ambience

Date: 2026-09-27 · Status: plan accepted by the user 2026-09-27 (sub-steps get their own sections)

## Context
- M11 gave the game art and animation. The game has no sound: no audio code and no audio files.
- The user picks audio as the next milestone.

## User choices (2026-09-27)
1. **Sources:** free licensed packs plus our own tool. Music and world sounds from free packs (Kenney CC0,
   OpenGameArt). A Python tool makes the small UI blips and System chimes.
2. **Music:** a track per kind of place that changes for night, winter, fights and big battles, plus special
   tracks for canon moments (Christmas, the solstice, Erin's play and others), picked by data.

## Decisions
- **Core does not change.** Audio is presentation only (`ui/`, `world/`, `game/assets/audio/`). No save
  version change. The view reads state and never changes it (rule 1).
- **Volumes are user settings, not game state.** They live in `user://settings.cfg` (Godot `ConfigFile`).
  Rule 2 covers game state; a load does not change volumes.
- **No randomness (rule 3).** Sound variants play in a fixed round-robin order; pitch change comes from a
  fixed table by counter.
- **Content is data (rule 4).** New `game/data/audio.json` maps cues, moods, tracks and canon moments to
  files (schema shown to the user before M12.1, rule 11). Objects that make a sound get an optional
  `"sound"` in `data/objects.json` (asked before M12.4).
- **Fallback:** a missing file or cue gives silence and one warning. Headless tests use Godot's dummy
  audio driver.
- **Buses:** `Master` with `Music`, `Ambience`, `SFX` and `UI` under it (`game/default_bus_layout.tres`).
- **Formats:** music and ambience loops as OGG Vorbis or MP3 (as the author ships them; Godot imports both, so
  no converter is needed) with `loop=true` in the `.import`; short effects as OGG or WAV. `.import` files
  stay in git (ADR 0001). About 60 MB of audio at most (was 40 MB; the user raised it in M12.3).
- **Licences:** CC0, CC-BY or CC-BY-SA only. Every file gets a line in `CREDITS.md`. The tool's blips are
  CC0. No AI-made audio (as for art, DESIGN §7).
- **No new addon or pip package.** Godot has the audio nodes; `tools/build_sfx.py` uses only the Python
  standard library (`wave`, `math`).

## Design
- `ui/audio.gd`: autoload `Audio`. Two music players (cross-fade), an ambience player, a pool of effect
  players, a UI player, and `AudioStreamPlayer2D` for object sounds.
- Pure helpers, tested headless: `world/sound_cues.gd` (AnimDiff events, ground tiles, actions and System
  page kinds to cues) and `world/music_pick.gd` (the track for a state: canon moment > wave stage > fight >
  scene stage > place mood with day / night / winter > default).
- `WorldView` emits the cues of each refresh as a signal; `main.gd` passes them to `Audio`.

## Plan (one branch + PR each)
- **M12.0 Audio spike.** Sources and licences, `game/assets/audio/`, CREDITS, buses, `Audio` skeleton, first
  blips. One title track, footsteps and a hit. The user approves the sound.
- **M12.1 Audio core + settings.** `audio.json`, cross-fade, `user://settings.cfg`, Options menu.
- **M12.2 Sound effects.** UI, System pages, footsteps by ground, doors, object use, combat, monster voices.
- **M12.3 Music.** Place moods with day / night / winter, fight, big battle, warm scene.
- **M12.4 Ambience.** Area beds and object sounds.
- **M12.5 Canon moments.** At least 6 moments with their own music; a sad sting for deaths in the news.

## M12.0 Audio spike (2026-09-27)
- **Downloads (user OK 2026-09-27):** Kenney "Impact Sounds" (CC0, 0.8 MB zip), Kenney "RPG Audio" (CC0,
  1 MB zip; kept in the scratchpad for M12.2, nothing from it in the repo yet) and "Medieval: The Old Tower
  Inn" by RandomMind (CC0, 2.5 MB MP3). Only the files we use are in git: 20 footsteps (grass, wood, snow,
  concrete), 5 punches and the one track. `CREDITS.md` has a new "Audio" section.
- `game/default_bus_layout.tres` (Godot loads it by default): Music, Ambience, SFX, UI under Master.
- `ui/audio.gd`: autoload `Audio`. A pool of 8 effect players, one UI player, one music player. Cue variants
  go round-robin; pitch from a fixed table (UI sounds keep their pitch). Every button in the game ticks when
  the keys move the focus to it and plays `ui_ok` / `ui_back` when pressed (hooked through `node_added`, so
  menus need no audio code).
- `world/sound_cues.gd` (`SoundCues`): footstep cue by ground tile (snow covers the outdoor ground in
  winter) and a `hit` cue from AnimDiff hits. `WorldView` emits `sounds(cues)` after each refresh;
  `main.gd` sends them to `Audio`. The System dialog chimes when it opens.
- The title track plays on the title screen and in the game (the music picker is M12.3).
- **Temporary:** the cue and track tables are constants in `audio.gd` and `sound_cues.gd`. M12.1 moves them
  to `data/audio.json` (rule 4).
- `tools/build_sfx.py` makes `ui_move`, `ui_ok`, `ui_back` and `chime` (sine notes with bell partials,
  22 050 Hz mono WAV, standard library only); `--check` compares the files on disk.
- Tests: `unit_audio.gd` (9), `tools/tests/test_build_sfx.py` (4). GUT 745/745 (80 scripts), Python 77/77.

## M12.1 Audio core + settings (2026-09-27)
- **Schema OK (user, 2026-09-27):** `game/data/audio.json`, as drafted. Sections: `sounds` (cue: `bus`,
  `volume_db`, `files` relative to `res://assets/audio/`), `music` (track: `file`, `volume_db`), `moods`
  (`by_map`, `by_location`, `default`), `mood_tracks` (mood: `day` / `night` / `winter_day` / `winter_night`),
  `states` (`title`, `fight`, `battle`, `scene`), `moments` (list: `id`, `track`, `when_flags`, `unless_flags`,
  `areas`, `stages`), and the cue maps `footsteps`, `actions`, `combat`, `pages`, `ui`, `ambience`, plus
  `enemies` (type: {event: cue}). Sections for later steps are empty for now.
- `footsteps` key `winter` is the step on snow-covered ground: in winter, outdoors, a tile with a
  `winter_color` in tiles.json and a footstep of its own sounds like snow.
- `ui/audio_db.gd` (`AudioDb`): pure loader, lookups and `validate` (every file exists, every reference is
  known, buses and mood variants are legal). Bad data never stops the game: a bad cue is silent, and `Audio`
  prints the problems once as warnings. The M12.0 constant tables are gone.
- `ui/audio_settings.gd` (`AudioSettings`): linear 0..1 volume per bus (Master, Music, Ambience, SFX, UI) and
  a mute switch, in `user://settings.cfg` section `audio`. A bus at 0 is muted. Not in `GameState`.
- `Audio` cross-fades music with two players (1.5 s; the new track rises from -60 dB). `play_key(section, key)`
  plays a mapped cue. GUT runs use `user://test_settings.cfg` (`test_support/gut_pre_run.gd`).
- `ui/options_menu.tscn` (`OptionsMenu`): sliders Volume, Music, Ambience, Effects, Menu sounds, and "Mute all
  sound". An Options button in the title menu and the pause menu. Each change applies and saves at once.
- Tests: `unit_audio.gd` (12), `unit_audio_data.gd` (8), `unit_audio_settings.gd` (8). GUT 762/762
  (82 scripts), Python 77/77, validator 0 errors.

## M12.2 Sound effects (2026-09-27)
- **Downloads (user OK 2026-09-27):** "Swishes Sound Pack" (artisticdude, CC0, 0.4 MB), "80 CC0 creature SFX"
  and "40 CC0 water / splash / slime SFX" (rubberduck, CC0, 1.9 MB and 2.3 MB), plus the Kenney RPG Audio pack
  from M12.0. Only used files are in git (audio folder now 5.5 MB). Creature files get a `creature_` prefix,
  splashes a `water_` prefix, so names never clash.
- **Combat** (`SoundCues.from_events`, from AnimDiff): hit (a punch; `hurt`, a heavier punch, when the player
  is hit), the hit monster's voice, fall, a gone monster's voice (else `gone`), swing. Each cue sounds at most
  twice per change (`MAX_SAME`), so a 40-Goblin battle stays readable. Block, throw and drop sound when the
  command works.
- **Monster voices** (`enemies`, all 36 types): Goblins grunt and cry out, Hobs are deeper, bugs click (Rock
  Crab, Ashfire Bee, Antinium), the Razorbeak shrieks, the undead moan, the Crypt Lord, Skinner and the Snow
  Golem roar when they fall. **Gnolls get human pain sounds, not barks:** Gnolls, Goblins and Antinium are
  people in the books. Human foes have a pain sound only.
- **Use menu** (`actions`): 23 of the 35 actions have a sound (cooking, serving, cleaning, washing, repairs,
  chopping, water, foraging, weapon practice, coins for trade and deliveries, chess, the faerie twinkle, books,
  bandages); talk, travel, sneak and watch stay quiet. Use-menu ids: sleep (cloth), take, buy / sell (coins),
  use (eating), ride (creak), portal (a magic shimmer). `door` sounds on a step between an indoor and an
  outdoor map. These keys live in `actions` (same key -> cue shape; no schema change).
- **System pages** (`pages`, by page kind): level up, class offer (and the drift warning), knock-out and
  collapse, morning, news and rumors (a page turn), welcome (the chime). Confirm and result pages are silent
  (the button already clicks). A kind not listed plays `open`.
- `tools/build_sfx.py` adds `level_up`, `offer`, `knockout`, `morning`, `portal`, `sparkle`.
- Tests: `unit_sound_cues.gd` (9): the rules, and that the data covers every enemy type, only real action ids
  and every page kind. GUT 771/771 (83 scripts), Python 77/77.

## M12.3 Music (2026-09-27)
- **Downloads (user OK 2026-09-27, all CC0, 26.6 MB):** RandomMind "Market Day" (loop), "The Bard's Tale",
  "King's Feast", "Medieval: Battle"; cynicmusic "Town Theme RPG", "Battle Theme A"; pauliuw "The Field Of
  Dreams"; kindland "Forgoten tomb ambience". The user raised the audio limit to about 60 MB (audio is 33 MB now;
  M12.5 needs room for special tracks). All music `.import` files have `loop=true`.
- **Moods (by map, all 15 maps):** `inn` (inn hill and inside: The Old Tower Inn by day, The Bard's Tale at
  night), `inn_celum` (the Frenzied Hare: Celum's tune by day, The Bard's Tale at night), `liscor` (gate and
  market: Market Day), `celum` (Town Theme), `wilds` (Floodplains, road camp, outside the Ruins: The Field Of
  Dreams; Forgotten Tombs at night), `dark` (bee cave, the rift, Esthelm ruins: Forgotten Tombs). Default
  `wilds`. No winter variants yet (they fall back to day / night).
- **States:** `fight` (Medieval: Battle, any fight), `battle` (Battle Theme A, a staged fight with foes left
  while the player is in its area), `scene` (King's Feast, any live scene stage), `title` (The Old Tower Inn).
- `world/music_pick.gd` (`MusicPick.track`): moment > battle > fight > scene > place mood with day / night
  (`Atmosphere.darkness` >= 0.5) / winter (`Winter.on`). Night variants fall back: winter_night -> night ->
  winter_day -> day. Moments hold on `when_flags`, `unless_flags`, `areas` and `stages` (a live scene or the
  staged fight in progress); M12.5 fills them.
- `main.gd` asks `MusicPick` after every redraw; `Audio.music` keeps a playing track and cross-fades a new one.
- Tests: `unit_music_pick.gd` (9), including every real map has a mood with a day track and the game screen plays
  the place music. GUT 780/780 (84 scripts).

## M12.4 Ambience (2026-09-27)
- **Downloads (user OK 2026-09-27, 7 files):** JaggedStone "Loopable Dungeon Ambience", Wolfgang_ "Crickets
  Ambient Noise", isaiah658 "Ambient Bird Sounds", SketchMan3 "wind whoosh loop", PagDev "Fireplace Sound loop"
  (all CC0); Gregor Quendel "Free Crowd Cheering Sounds" (CC-BY 4.0) and IMadeIt "Single Bee sound" (CC-BY 3.0).
  The well uses rubberduck's `loop_water_02.ogg` (the M12.2 water pack). 8 loops, 3.2 MB, in
  `assets/audio/ambience/`; every `.import` has `loop=true`.
- **Cutting loops:** a scratchpad script (ffmpeg + numpy, not in the repo, so no new tool dependency) takes a
  stretch, cross-fades its last 2-3 s into its start and writes OGG. Volumes were set from the measured mean
  loudness: a bed sits about 10 dB under the music.
- **Area beds** (`audio.json` `ambience`, the user OK'd the new shape with M12.4): `by_map` names a place, else
  `outdoor` / `indoor` (indoor = quiet: the fire makes the sound). `beds`: place -> {day, night, winter_day,
  winter_night} cue with the music fallback (`MusicPick.pick_variant`). Outdoor: birds by day, crickets at night,
  wind in winter. Market (Liscor market, Celum square): the crowd by day, crickets at night, wind on winter nights.
  Tavern (the Frenzied Hare): the crowd. Cave (bee cave, the rift): the dungeon bed. `ambience` left `CUE_MAPS`.
- **Object loops** (`objects.json` `"sound": {"cue", "radius"}` in cells, user OK 2026-09-27): fires (brazier,
  campfire, hearth, stove), the well (water) and the bee nest (bees). `WorldView` emits `area_loops` on a new map
  (`AmbiencePick.loops_on`); `Audio.place_loops` puts one `AudioStreamPlayer2D` per object under
  `WorldView.loop_spots` (max distance = radius; the camera is the listener).
- `Audio`: music and bed share a two-player `Fader` (cross-fade). `main.gd` asks `AmbiencePick.bed` after every
  redraw; the title screen fades the bed out.

## M12.5 Canon moments (2026-09-27)
- **Downloads (user OK 2026-09-27, all CC0, opengameart.org, 7 tracks):** RandomMind "Fantasy: Lament for a
  Warrior's Soul" and "Fantasy: Rising Moon"; VishwaJai "Doom in the Morning"; nene "Fall of Nightmares" (a 15.5 MB
  WAV, turned into a 1.9 MB OGG with ffmpeg); isaiah658 "Heavenly Loop"; Kistol "Snowfall" (looped); SkyleTheFrench
  "Cold Hands". Audio is now 56 MB (limit about 60 MB). Every music `.import` has `loop=true`. Volumes set from the
  measured mean loudness, so each track sits near the place music.
- **9 moments** (`audio.json` `moments`, data order; each ends with its stage, so no flag can hold a track for
  ever): Erin kills the Goblin Chieftain and Klbkch dies (`lament`), Skinner's dead in Liscor and Rags kills
  Skinner (`undead_siege`), the Frost Faeries' banquet (`faerie_night`), Pawn becomes an Acolyte (`heavenly`),
  Romeo and Juliet and Frozen (`stage_play`), the last battle of Esthelm (`last_stand`), and Christmas night
  (`christmas`). A staged fight's moment plays while `combat.stage_run` is that event (it clears when the fight
  ends, on leaving the area and at night); a scene's moment plays while the scene is live.
- **Sad sting:** `tools/build_sfx.py` makes `sad_sting` (a slow minor line down to a low D). The Local News page
  gets `"deaths"` (`SystemMessages.news_deaths`): NPCs killed tonight by a canon event that ran (done,
  substituted or changed), has news (its own or its hook's) and a `kill` effect whose NPC is dead now (a role
  filled by another NPC counts that NPC, as the director does). `SoundCues.page_sound` plays the `pages` key
  `death` for such a page, else the page kind's cue. `death` is a new key in the existing `pages` map (no schema
  change). A death with no news (Toriska, the Skinner's first victims) plays no sting.
- Tests: `unit_canon_moments.gd` (7): at least 6 moments with real tracks and real canon stages, a fight moment beats
  the battle music, a scene moment plays only on its area, `news_deaths` rules, the news page carries the deaths,
  `page_sound`, and the dialog plays the sting. GUT 800/800 (86 scripts), Python 77/77, validator 0 errors.
