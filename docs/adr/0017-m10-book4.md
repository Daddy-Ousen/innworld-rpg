  - M10.1: 3.26 G – 3.29 G
  - M10.2: 3.30 – 3.31 G + Wistram Days 1–7
  - M10.3: 3.32 – 3.35

## M10.0 The Albez door (engine, save v13)
**Map objects.** There are two new optional fields:
- `when_flags` / `unless_flags`: the object is on the map only while the flags hold.
  - `MapDb.sync_flags` keeps the set of hidden objects. The set is part of `overlay_key`, with the overlays.
  - `objects_near` and the new `objects_on` skip hidden objects.
  - The map view does not draw hidden objects.
  - An object with flags must not be solid.
- `portal`: `{"to", "pos", "power_flags"}` makes the object a magic door. The map validator checks:
  - the target map;
  - that the arrival tile is walkable;
  - the flag list;
  - that `rules.portal` and the action `travel` exist.

**Rules.** There is a new optional section, `rules.portal`, with these fields: `trips_per_day` (4), `minutes` (1), `line`, `dry_line` and `spent_line`. In the text a trip is instant. Here it takes one minute, so that it is a travel action.

**Portal.** `core/portal.gd` holds `Portal.use`. You call it with `Commands.portal`, the use menu or the console command `portal <object>`.
- It refuses when a power flag of the door does not hold (`dry_line`).
- It refuses when the player has no trips left today (`spent_line`).
- Otherwise it logs a travel action with `context.portal`, counts the trip and moves the player. The player feels no cold on the way, as on a covered ride.

**Save v13.** `PlayerState` has two new fields, `portal_day` (-1 = none) and `portal_trips`. Migration 12→13 adds them.

**World data.**
- A new indoor map, `celum_stitchworks` (location `stitchworks`). It holds Octavia's counter (the Stitchworks shop) and the door.
- A door tile and an exit from Celum square at (1, 13).
- Two door objects, both powered by `erin.magical_grounds`:
  - `albez_door` in the inn, shown by `albez_door.at_wandering_inn`;
  - `albez_door_celum` in Stitchworks, shown by `albez_door.anchor_at_stitchworks`.
- The canon batches set these flags:
  - M10.2 (3.30) sets the anchor flag.
  - M10.3 (3.32–3.33) sets the inn flag and `erin.magical_grounds`.
- The map size, the layout and the door places are guesses.

**Tests.** `unit_portal` is new. Its 11 tests check that:
- the door data loads;
- there is no door before its flags are set;
- a dry door stays shut;
- the player can step through and back;
- the player gets four trips, and more on the next day;
- the Celum end needs its own flag;
- the shop door leads in, and the counter sells;
- the trip count is saved;
- a v12 save loads;
- bad portal data and bad portal rules are reported.

`unit_interact` expects the new `portal` option field.

**Results.**
- GUT: 640/640 (68 scripts).
- On screen: the door shows in the inn, and the use menu offers the trip.
